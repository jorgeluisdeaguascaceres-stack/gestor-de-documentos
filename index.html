Matriz de permisos

Solo el usuario maestro administra permisos. Active o desactive el acceso de cada persona a cada módulo con los interruptores. La columna Editar autoriza a modificar admisiones guardadas y la columna Eliminar autoriza a borrar notas clínicas. El permiso de Config está reservado y solo tú puedes concederlo.

Permiso para crear notas

Active el tipo de nota que cada persona puede crear y editar. Ver una nota siempre está permitido a quien tenga acceso al módulo Registro: por eso un médico puede leer una nota de enfermería aunque no la pueda redactar, y una auxiliar puede leer una historia clínica o una terapia aunque no la pueda crear. Pase el cursor sobre cada columna para ver el tipo completo.

Respaldo y traslado de datos

Como la información se guarda en este dispositivo, use el respaldo para pasar todo a otro PC o celular. Exporte aquí, envíe el archivo al otro equipo (correo, WhatsApp, USB) e impórtelo allá. No sincroniza solo y no reemplaza a un servidor; es un traslado manual.
